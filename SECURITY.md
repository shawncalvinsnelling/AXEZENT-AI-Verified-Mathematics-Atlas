# Security Policy

## Reporting a vulnerability

Please report security vulnerabilities privately to **Axezentai@gmail.com**.

Do not open a public GitHub issue for a vulnerability that could expose credentials, customer information, entitlement infrastructure, or private AXEZENT systems.

A useful report includes the affected component, reproduction steps, likely impact, and any suggested mitigation.

## Secrets

This repository must not contain:
- Cash App passwords or PINs;
- billing API secrets;
- private signing keys;
- production database credentials;
- customer license keys;
- confidential customer research.

## Supported public components

Security reports are accepted for the current public repository and available AXEZENT evaluation software. Enterprise support and disclosure terms may be supplemented by contract.
