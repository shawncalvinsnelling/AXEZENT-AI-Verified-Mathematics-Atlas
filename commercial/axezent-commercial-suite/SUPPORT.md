# AXEZENT Support

## Customer support

**Email:** Axezentai@gmail.com

For a technical support request, include:

- product name;
- version or commit, when known;
- operating system/runtime;
- the exact error message; and
- minimal steps needed to reproduce the problem.

Do not post license keys, private customer data, unpublished research, financial credentials, or proprietary source code in public GitHub issues.

## Public repository issues

Public GitHub issues may be used for bugs involving public AXEZENT artifacts and reproducible public examples.

Do not use a public issue for privacy requests, security reports, payment disputes, or confidential customer material.

## Preview service level

Preview products are provided without a guaranteed response-time SLA. Enterprise support levels and response targets exist only when the applicable written agreement establishes them.

## Privacy requests

Privacy requests should be sent to **Axezentai@gmail.com** with the subject line **Privacy Request**. See the [Privacy Policy](./PRIVACY_POLICY.md).

## Billing and refunds

Billing questions and refund requests should be sent privately to **Axezentai@gmail.com**. See [Billing & Activation](./PAYMENTS.md) and the [Refund and Cancellation Policy](./REFUND_CANCELLATION_POLICY.md).

## Responsible disclosure

Security issues should be reported privately to **Axezentai@gmail.com** rather than opened as a public issue when disclosure could put users or infrastructure at risk.
