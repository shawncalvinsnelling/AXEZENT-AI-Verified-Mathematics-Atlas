## Available now

### Six-Cycle Exact Certifier

The first public AXEZENT evaluation tool is executable:

- exact all-`s` coefficient implementation for the published `(6^s)` family;
- Python API and CLI;
- browser-based certificate generator;
- exact checks for the stated unimodality and strict-log-concavity properties;
- SHA-256 verification receipts; and
- CI regression checks through `s=250`.

Its certificate applies only to the published six-cycle family and stated checks. It is not independent peer review or a guarantee about arbitrary partitions.
